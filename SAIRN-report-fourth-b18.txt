WHY THAT IS THE DANGEROUS DIRECTION, in the file's own terms. The census gates

  under-count  -> the gate reads zero while legacy ciphertext exists, the
                  operator clears PREVIOUS, and the last key able to read those

                  null as "no secret stored".

SEVERITY STATED HONESTLY RATHER THAN MAXIMALLY: the affected value is a Stedi

unrecoverable data loss. IT IS A SAFETY CHECK THAT RETURNS A CONFIDENT ZERO IT
