Procedure Types
Your practice's own procedure list — code, description, fee, and default length. Not a bundled CDT code library (real ADA copyright constraint) — enter your practice's actual codes and fees below.
Add Procedure Type
CDT is republished every year and payment ties to the exact code reported, so a code that was right last year can be wrong for a service performed this one. Recording the edition and the effective window is what lets this app check a code against the date of service rather than against today. Leave the window blank and the code cannot be checked at all — it will say so rather than quietly pass.
