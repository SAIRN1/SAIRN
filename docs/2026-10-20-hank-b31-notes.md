## 1. The sync button — REMOVED (Michael's decision)
> **CONCEPT.** A control that can never do what its label says is removed — not left to fail, and not
> "fixed" into a write nobody reads.

Removed from `stonedesk.html`: the "Sync All Apps" button, its "Last sync" element, `sairnSyncAll`,
`sairnUpdateLastSync` and its on-load restore, and the `SAIRN_BRIDGE` constant only `sairnSyncAll` used.
The CSV Export button beside it is untouched.

**A defect b29 missed, found while removing it:** the onclick was
`sairnSyncAll();sairnUpdateLastSync()`. The second call is synchronous and unconditional, so the
"Last sync" time was stamped on every click whatever the server answered — b29's honest-failure fix
held inside the function, and the button stamped the time anyway. b29's live drive called
`window.sairnSyncAll()` directly and never clicked the button, so it could not see this. The lesson is
the drive's, not the code's: drive the control the user touches, not the function behind it.

`api/b29-stonedesk-sync-honesty.test.js` section A re-aimed to assert the absence (6 arms, each red
against the pre-removal page). Dead code noticed and left: `getBusinessContext()` (no callers) still
reads the now-unwritten `stonedesk_last_sync` key.
