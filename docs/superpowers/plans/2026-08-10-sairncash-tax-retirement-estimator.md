# SAIRNcash Tax/Retirement Estimator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build SAIRNcash's actual core value feature per
`docs/superpowers/specs/2026-08-10-sairncash-tax-retirement-estimator-design.md`:
quarterly self-employment tax set-aside, federal income tax estimate,
and SEP IRA/Solo 401(k) contribution optimization — all deterministic
math against real 2026 IRS constants, no dollar figure ever computed or
restated by Claude.

**Task 0 is blocking.** It fixes a cross-subscriber data-isolation bug
found during the design pass (Firebase sync is currently one global
path, not scoped per customer) — nothing in Tasks 1-4 may write real
financial data through the sync layer until this lands.

## Global Constraints

- Every dollar figure (SE tax, income tax, safe-harbor amount, SEP/
  Solo 401(k) estimate) is computed by pure, deterministic JS functions
  — never sent to or generated by Claude. Claude only explains an
  already-computed number or suggests an editable deduction category.
- Federal only — no state tax logic anywhere in this pass (spec §5).
- Self-employment income only — no W-2 interaction logic (spec §5).
- All constants live in one `TAX_YEAR_2026` object at the top of the
  script, each with an inline comment citing what it is and that it
  must be re-verified for any other tax year — no bare magic numbers
  scattered through the math functions.
- `python tools/checkblocks.py sairncash.html` /
  `div_balance_check.py` / `duplicate_global_check.py` clean after
  every change.
- Push Protocol: full local checks before push, real live-verify after
  (not assumed from a clean push).

### Task 1: Deterministic tax-math engine

**Files:** Modify `sairncash.html` (new script section, before the

- [ ] **Step 1: Write the constants and pure functions**

```js
// ── TAX MATH (2026) ──────────────────────────────────────────────
// Every function here is pure and deterministic -- same inputs, same
// output, every time. Claude never computes or restates any of these
// numbers; it only explains a result already produced here. Re-verify
// every constant against the current year's real IRS Rev. Proc. before
// this ships for a different tax year -- see design spec §1 for the
// 2026 sourcing.
const TAX_YEAR_2026 = {
  ssWageBase: 184500,          // 2026 SS wage base (up from $176,100 in 2025)
  addlMedicareThreshold: { single: 200000, hoh: 200000, mfj: 250000, mfs: 125000 },
  standardDeduction: { single: 16100, mfs: 16100, hoh: 24150, mfj: 32200 },
  sepCap: 72000,                // 2026 SEP IRA / combined DC plan cap
  solo401kDeferral: 24500,      // 2026 Solo 401(k) employee deferral, under-50
  // Full 7-bracket tables (10/12/22/24/32/35/37%) for each filing
  // status -- transcribed exactly from IRS Rev. Proc. 2025-32 (NOT
  // reconstructed from partial figures). Each entry: [incomeUpTo, rate].
  // Top brackets confirmed during design: single 37% above $640,600,
  // mfj 37% above $768,700 -- fill in the remaining thresholds from
  // the real Rev. Proc. table before this function is trusted.
  brackets: {
    single: [/* TODO: transcribe from Rev. Proc. 2025-32 */],
    mfj: [/* TODO */],
    mfs: [/* TODO */],
    hoh: [/* TODO */]
  }
};

function calcSeTax(netProfit) {
  const netSeEarnings = netProfit * 0.9235;
  const ss = 0.124 * Math.min(netSeEarnings, TAX_YEAR_2026.ssWageBase);
  const medicare = 0.029 * netSeEarnings;
  // Additional Medicare needs a filing status for its threshold --
  // computed in calcTotalTax below where filing status is in scope,
  // not here (this function stays status-agnostic on purpose).
  return { netSeEarnings, ss, medicare, ssAndMedicare: ss + medicare };
}

function calcAdditionalMedicare(netSeEarnings, filingStatus) {
  const threshold = TAX_YEAR_2026.addlMedicareThreshold[filingStatus];
  return netSeEarnings > threshold ? 0.009 * (netSeEarnings - threshold) : 0;
}

function bracketTax(taxableIncome, filingStatus) {
  const table = TAX_YEAR_2026.brackets[filingStatus];
  let tax = 0, lastCap = 0;
  for (const [cap, rate] of table) {
    const bandTop = Math.min(taxableIncome, cap);
    if (bandTop > lastCap) tax += (bandTop - lastCap) * rate;
    lastCap = cap;
    if (taxableIncome <= cap) break;
  }
  return tax;
}

function calcTotalTax(netProfit, filingStatus, retirementContribution) {
  const se = calcSeTax(netProfit);
  const addlMedicare = calcAdditionalMedicare(se.netSeEarnings, filingStatus);
  const seTax = se.ssAndMedicare + addlMedicare;
  const taxableIncome = Math.max(0,
    se.netSeEarnings - (seTax / 2) - TAX_YEAR_2026.standardDeduction[filingStatus] - (retirementContribution || 0)
  );
  const incomeTax = bracketTax(taxableIncome, filingStatus);
  return { seTax, incomeTax, totalTax: seTax + incomeTax, netSeEarnings: se.netSeEarnings, taxableIncome };
}

function calcQuarterlySetAside(ytdNetProfit, filingStatus, priorYearTaxLiability) {
  const estAnnual = calcTotalTax(ytdNetProfit, filingStatus, 0).totalTax; // extrapolated from YTD, refined as more income is entered
  const safeHarborBasis = priorYearTaxLiability
    ? Math.min(0.9 * estAnnual, 1.0 * priorYearTaxLiability) // 110% variant applied by the caller when priorYearAGI > $150k, not computed here
    : 0.9 * estAnnual; // no prior-year figure entered yet -- best available partial estimate, labeled as such by the caller
  return { estAnnual, safeHarborBasis, quarterlyAmount: safeHarborBasis / 4, hasFullBasis: !!priorYearTaxLiability };
}

function calcRetirementEstimate(netProfit, seTax, vehicle) {
  const effectiveRate = 0.20; // approximation of the true ~18.587-20% self-employed effective rate -- see design spec §1
  const base = Math.max(0, netProfit * 0.9235 - seTax / 2) * effectiveRate;
  if (vehicle === 'sep') return { estimate: Math.min(base, TAX_YEAR_2026.sepCap), cap: TAX_YEAR_2026.sepCap };
  if (vehicle === 'solo401k') {
    const employer = Math.min(base, TAX_YEAR_2026.solo401kDeferral > 0 ? TAX_YEAR_2026.sepCap - TAX_YEAR_2026.solo401kDeferral : base);
    return { estimate: Math.min(TAX_YEAR_2026.solo401kDeferral + employer, TAX_YEAR_2026.sepCap), cap: TAX_YEAR_2026.sepCap };
  }
  return { estimate: 0, cap: 0 };
}
```

**Note the `brackets` table is intentionally left as a TODO in the
first draft above** — the design spec explicitly flags that only the
top-bracket thresholds were confirmed during design (spec §1) and the
full table must be transcribed exactly from IRS Rev. Proc. 2025-32,
not approximated. Transcribing it accurately is this step's own real
sub-task; do not write placeholder numbers into `brackets` and move
on.
