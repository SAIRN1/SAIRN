## 1. CONCEPT, STATED BEFORE THE CODE

`QUERY_RE` only matches a table name written into a URL. So a table reached
through a constant or a generic handler reads as unqueried. The fix: also
count a table when its exact name appears as a whole quoted literal or a map
key on a live code line, bounded to names some `sql/` file creates. Then check
the output against the known 37 before trusting it.
