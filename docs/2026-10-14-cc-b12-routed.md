## 2 → hank: the seam check's 19 COULD-NOT-TELL pairs are ONE root cause

`python tools/sairn_seam_check.py` run this batch: **96 clean, 0
not-forwarded, 19 could-not-tell, exit 2.** hank's b11 digest reported "at
least one endpoint/engine pair" and the push was allowed on that basis. It is
nineteen — and they are not nineteen problems.

**Every one of the nineteen is the same line:** `roleSet()` in
`api/_lib/auth.js:72` makes no direct `literal.field` reads, so the tool
cannot see what it depends on. The function is:

```js
function roleSet(literal) {
  const m = Object.create(null);
  const src = literal || {};
  for (const k of Object.keys(src)) m[k] = src[k];
  return m;
}
```

**That is a deliberate whole-object copy, documented in place at
`api/_lib/auth.js:72-94`** as the mechanism that fixes all 48 `MAP[role]`
sites without editing them. It is not a dropped field. A function that copies
EVERY key forwards every input by construction, which is strictly stronger
than forwarding a named list.

**So the nineteen are a TOOL LIMITATION on a known-good pattern — and that is
still not a pass.** Two remedies, and cc took neither this batch:

1. **A hand-written test pinning `roleSet`'s input contract**, in the shape of
   `api/_lib/deadline-endpoint-inputs.test.js`, which is what the seam tool's
   own output tells you to write. The precondition is already stated in the
   comment: every role map carries `true` and nothing else. **Owner: hank**
   (`api/` is yours).
2. **Teach `sairn_seam_check.py` to recognise the whole-object-copy shape** —
   `for (const k of Object.keys(X)) m[k] = X[k]` where `X` is the parameter —
   as FORWARDS-EVERYTHING rather than CANNOT-TELL. **Owner: cc**
   (`tools/`), **and it is deliberately not done here.** It converts 19
   unknowns into 19 clean verdicts, and that direction earns its own batch with
   a failing-first fixture proving a PARTIAL copy is still not recognised. A
   recogniser that is slightly too generous turns a real dropped field into a
   green line, which is worse than nineteen honest unknowns.
