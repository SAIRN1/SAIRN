SAIRN License Key Manager

Generate and manage license keys for paying StoneDesk customers. Keys are stored in Vercel environment variables.

Generate New License Key

To activate this key:
1. Copy the JSON entry above
2. Go to vercel.com/dashboard → your SAIRN project → Settings → Environment Variables
3. Find SAIRN_KEYS → Edit → add the new entry inside the JSON object
4. Click Save → Redeploy. Key is live in ~60 seconds.

How to Activate a New Customer

Step 1 — Customer pays (Zelle, check, Stripe link, whatever). Confirm payment received.
Step 2 — Open this tool. Enter shop name, app, plan. Click Generate.
Step 3 — Copy the key and the JSON entry. Go to Vercel → SAIRN project → Settings → Environment Variables → SAIRN_KEYS. Add the new entry and save.
Step 4 — Email the customer their license key and the 7-Day SOP. Tell them to go to their app → Formula Editor → License Key field → paste key → Save.
Step 5 — Done. They now have unlimited AI calls, higher token limits, and their key in the footer of every response.
