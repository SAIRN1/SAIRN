Controlled-Substance Count Policy
No federal or uniform ALF requirement exists for this. Default below is the one converged best-practice pattern found in research (a joint count, two signatures). The state-specific options are each one real state's own confirmed rule, not a claim that any state's approach is universal -- select only the one that actually matches this facility's licensing state.
Missed / Late Care Alerting
A dose counts as late once it passes its scheduled time plus the window below. There is no default -- this app will not assume a window, because a guessed one would flag on-time nurses as late.
Text-message alerts are not available on this deployment -- no SMS provider is configured for this platform. Alerts are delivered in-app and by email only. This is stated rather than offered-and-silently-dropped.
Billing Rate Card
Room & board is always private-pay -- Medicaid HCBS waivers never cover it. The care-level rate is billed privately unless this facility accepts Medicaid HCBS AND the resident's payer is set to Medicaid HCBS Waiver.
Edit Facility Profile
The licensing state is the jurisdiction this facility is actually licensed in. It is validated server-side against the real two-letter US state list and is stored per facility, not per account -- a campus that also holds a separately licensed skilled-nursing entity will record that one on its own. Nothing enforces state rules yet; this field exists so the compliance-rules engine has a real jurisdiction to work from when it is built, instead of guessing. This is separate from the Medicaid HCBS waiver state under Billing and is deliberately not derived from it.
