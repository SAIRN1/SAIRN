PINs are no longer set here. Each employee has their own credential, stored as a scrypt hash server-side and never in this page. An Owner provisions them through api/mech-auth.js (setup), and deactivates a departing employee with set_active — the credential row is kept, never deleted, so the person stays auditable.
No UI for this yet. Stated rather than implied: no SAIRN app ships a client for set_active, so today it is a server call. Building that UI is the remaining piece.
