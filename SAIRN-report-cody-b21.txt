5. THE METHODOLOGY ITEM -- CONVENTION 37
----------------------------------------
docs/2026-09-13-cross-domain-disciplines.md gains:

  37. A TWO-SOURCE CONFLICT IS UNDER-DETERMINED -- the resolving source is the
      one the quantity is USED on, and when both sides turn out correct the
      error was in your MODEL of the subject.

A DEFINING SOURCE AND A DESCRIBING SOURCE CANNOT SETTLE EACH OTHER. The
definition says what the number should be, the description says what somebody
published, and NEITHER SAYS WHICH POPULATION THE NUMBER APPLIES TO. The arbiter
is the OPERATIONAL ARTEFACT -- the form, the config file, the table the value is
read out of -- because that artefact has to name the population to be usable at
all. Go to the thing that USES the quantity, not to a third thing that defines
it again.

AND THE SECOND HALF IS THE HARDER ONE: IF BOTH SIDES OF YOUR DOCUMENTED
CONFLICT TURN OUT TO BE CORRECT, THE DEFECT WAS NEVER IN EITHER SOURCE. It was
in the model you compared them against. The statute quote was right. The page
quote was right. The model was one amendment stale -- it held "section 45B has A
floor", and section 45B has had two since tax years beginning after 2024. AND
SECTION 7.4 OF THE SAME DOCUMENT ALREADY LISTED THE BEAUTY-SERVICE LIMB and
never asked whether the limb had its own floor, which is the whole distance
between having the fact and having the model.

WHY IT NEEDS A NUMBER: writing a conflict down carefully is exactly what makes
it feel resolved -- both sides quoted, both dated, the disagreement explicit --
so a well-documented conflict reads as understood and a misdiagnosis inside one
is invisible. A CONFLICT CAN BE DOCUMENTED PERFECTLY AND DIAGNOSED WRONGLY.

THE CHECKABLE FORM, since a convention nobody can apply is an essay. Before
publishing "source A and source B disagree": (1) name the POPULATION each
source is talking about, and if either does not state one, THAT is the finding
and it is a different finding from disagreement; (2) find the artefact the
quantity is read out of and check whether it carries MORE THAN ONE value for
what you assumed was one; (3) ask what would have to be true for BOTH sources
to be correct -- if that state is possible, the conflict is not established and
your model is the first suspect.

WHAT IT DOES NOT SAY: not that guidance pages are reliable -- the page is still
wrong and a food-and-beverage employer still uses $5.15, and what changed is
WHAT KIND of wrong; not that a third source always exists, because a purely
definitional conflict with nothing downstream genuinely is a question for
someone outside, which is what b20 did and was right to do; and NOT a licence
to stop documenting conflicts, because the verbatim dated quotations are
exactly what made this correction cost one read.
